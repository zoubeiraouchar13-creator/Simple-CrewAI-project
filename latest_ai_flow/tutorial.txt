Create the workflow :
    crewai create flow latest-ai-flow
    cd latest_ai_flow (you must be in the project root to run crewai)

Create a .venv
pip install crewai, crewai_tools

Allow ExecutionPolicy :
    - In powershell run : powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Create the workspace : crewai install

Create :
    -config/agents.yaml
        (role, goal, backstory)
    -config/tasks.yaml
        (description, expected_output, agent, output_file)

Create Scripts :
    -src/project/crews/content_crew.py
        @crewbase (agent, task, crew)
    -src/project/main.py
        (Basemodel, start, listenn kickoff)

Create the .env :
    SERPER (https://serper.dev), model used, API_BASE(localhost)

If you have some troubleshoting with prerelease version, then add this to pyproject.toml:
    [tool.uv]
    prerelease = "allow"
